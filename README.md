# QQ农场数据站

QQ 农场（QQ Farm）全功能辅助工具，覆盖收益计算、图鉴查询、道具浏览、装扮预览等。移动端优先的渐进式 Web 应用。

## 功能一览

| 入口 | 功能 | 说明 |
|------|------|------|
| 🏠 首页 | 仪表盘 | 快速计算器 + 全功能导航 + 数据统计 |
| 🧮 计算器 | 经验收益计算器 | 等级/土地配置/紫晶土地/施肥对比/TOP20 排行 |
| 📖 图鉴 | 作物图鉴 | 全部种子，点击卡片查看成长阶段与属性 |
| | 土地图鉴 | 普通/红/黑/金/紫晶 5 种土地，24 块地开垦与升级需求 |
| | 变异图鉴 | 10 种变异效果 + 黄金超变来源 + 超变一览 |
| | 装扮图鉴 | 6 类装扮（小屋/木牌/栅栏/盆栽/仓库/道路等） |
| 🛒 道具 | 道具目录 | 12 个分类全覆盖（种子/果实/货币/工具/化肥/狗粮等） |
| 🛠️ 工具 | 等级查询 | Lv1~Lv200 经验表，搜索与分段定位 |
| | 土地升级所需 | 各地块到红/黑/金/紫晶的等级和金币需求 |

## 技术栈

- **框架** React 19 + TypeScript
- **构建** Vite 6
- **样式** Tailwind CSS 4
- **动画** Motion (Framer Motion)
- **图标** Lucide Icons

## 本地运行

```bash
npm install
npm run dev
```

访问 `http://localhost:3000` 即可访问。
